# 设置页混合式设计规范

四个设置分类统一使用这套规范。四分类 NavigationView、方向滑动动画、页面缓存与原有设置保存流程继续沿用。

## 两类卡片

- **普通设置行**：一张卡片只承载一个设置项，4px 圆角，18px 横向、14px 纵向内边距。同组间距 4px，组间距 28px。分类标题放在卡片外。
- **环境信息卡**：用于目录、Java 等需要同时展示配置、状态与快捷操作的重要环境。6px 圆角、20px 内边距；图标与标题在上，配置摘要与路径居中，状态和操作在下。常用数字参数继续使用普通设置行。

## 内容与交互

- 普通设置行从左到右为：20px 图标、标题与简短说明、操作控件。复用 `Controls/SettingsRow`，新增的可选 `IconGlyph` 也可供后续外观、账户和高级页使用；未指定时沿用原来的无图标布局。
- 开关靠最右侧；互斥选项使用 ComboBox；滑块与当前数值并排放在右侧。只有极窄宽度时，操作区才换行，避免控件溢出。
- 操作名称不附加省略号。主题下拉框按选中文字自然取宽；主题色色点放在左侧，右侧依次为恢复品牌色和自定义，自定义处于最右侧；窄窗口换行后仍右对齐。
- 次要和复杂配置复用 `Controls/SettingsExpander`。标题使用普通设置行的布局和至少 76px 高度，Java 卡片内的简短标题允许使用 44px 紧凑尺寸。
- 共享展开组件复用原外观页的 220ms 高度与透明度动画，支持中途反向收起、页面卸载、窗口重排和系统关闭动画。动画结束后按需滚动，展示新内容；内容过高时保留标题和开头，不强制跳到页面最底部。
- 公共组件用于常规页的 Java 与迁移导入、外观页的亚克力细调，以及高级页的 JVM / 游戏参数。各项操作继续连接原有处理事件，保存时机不随展开或收起改变。
- 路径支持选择、复制与悬停查看全文。Java 自动模式显示发现的版本与检测数量，不把某个候选运行时标为实际启动所用版本；手动模式显示所选版本、架构、安装路径及检测状态。保留但未检测到的路径明确提示检查安装位置。

## 色彩与适配

- 游戏目录使用低饱和蓝底，Java 使用低饱和绿底，全部通过 ThemeResource 的浅色、深色和高对比资源切换。文字继续使用全局文字画笔，不用彩色文字取代状态说明。
- 账户信息卡复用 `BrandSoftBrush` 对接用户主题色；普通参数行使用中性背景，避免整页出现大量彩色块。
- 账户卡按内容取高，头像与文字垂直居中；空状态消息折叠，不预留底部空白。目录和 Java 卡片右下角复用现有图标作为低透明度水印，局部裁切且不拦截点击。
- 环境卡可用宽度达到 640px 时并排，否则上下排列；参数保持单列，便于扫描。编辑区随宽度收缩，较窄设置行沿用原有换行能力。

## 分类侧重

- 常规：少量环境信息卡，加紧凑的下载、启动和窗口参数。
- 外观：主题与材质预览为主，细调参数遵循设置行规范。
- 账户：身份摘要与状态优先，操作按原有账户行为连接。
- 高级：中性、简洁，复杂参数按需展开。

账户页突出身份状态，登录、注册、头像、管理与退出各为一项。高级页保持中性，两个参数编辑器分别按需展开。外观页保留四种材质预览和主题色样本，通透程度、鲜艳程度和不透明度改用右侧滑块。
